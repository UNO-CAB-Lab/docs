# Getting Your Data

#### Qualtrics Survey Data

As respondents complete your study in the CAB Lab, Qualtrics will store their responses, along with any metadata you specified when you designed the survey.

When you request your data from the CAB Lab, we will send you an Excel (.xslx) spreadsheet containing these responses. **This XLSX file does not contain any sensor data.**

**Optional**

As the creator of the Qualtrics survey, you will also have access to its response data. Should you decide to obtain your response data before you're done running your study, you can follow these steps:

1. In the Qualtrics survey, navigate to the 'Data & Analysis' tab.
2. From here, click 'Export & Import' > 'Export Data...'
3. You can choose to export a file (CSV, TSV, XLSX, etc.) containing Values or Labels. Be sure to download all fields and select what you'd like to export.
   1. The CAB Lab will always send you an XLSX file containing Labels. If you're exporting your data ahead of time and you plan to use the CBACABLab library to analyze it, you should export this same file type.

#### Sensor Data

In addition to Qualtrics survey data, the CAB Lab collects sensor data as respondents take your study. Depending on the sensors you're using for your study, these files will contain various readings.

Note: Qualtrics response data exports as _one combined file_, while sensor data exports as _individual CSV files_ for every respondent.&#x20;

**These CSV files do not contain any survey responses.** By granting the CAB Lab collaborator access to your Qualtrics survey, we're able to automatically pair these results with survey responses.&#x20;
